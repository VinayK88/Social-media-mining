## About this collection

This repository preserves earlier notebook work spanning social-platform data acquisition, data persistence, regression, classification, cross-validation, and model evaluation.

It is presented as a **learning / foundational analytics archive**. Platform APIs and access policies evolve, so historical collection notebooks may require adaptation before they can run against current services.
